# 示例

下面的游戏都在仓库的 [`examples/`](https://github.com/sapling2d/sapling2d/tree/main/examples) 目录里，源码就是普通的 sapling2d 项目。点击画面开始玩；在电脑上用键盘，在手机上用触摸。

想在本地运行某一个：

```sh
pnpm install
pnpm --filter example-plane dev
```
